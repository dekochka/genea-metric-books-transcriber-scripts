## Directory Purposes

**config/**
- Purpose: YAML configuration files for different projects
- Contains: Example configs, user configs, project-specific configs
- Key files:
  - `config.yaml.example`: Legacy flat format example
  - `config.local.example.yaml`: LOCAL mode nested format example
  - `config.googlecloud.example.yaml`: GOOGLECLOUD mode nested format example
  - `config-*.yaml`: Real project configurations

**wizard/**
- Purpose: Interactive configuration wizard subsystem
- Contains: Controller, steps, utilities, i18n
- Key files:
  - `wizard_controller.py`: Main wizard orchestrator
  - `steps/base_step.py`: Abstract base class for wizard steps
  - `steps/mode_selection_step.py`: Mode and credential selection
  - `steps/context_collection_step.py`: Title page context extraction
  - `steps/processing_settings_step.py`: Processing parameters
  - `config_generator.py`: YAML config generation
  - `prompt_assembler.py`: Template-based prompt assembly
  - `title_page_extractor.py`: AI-powered title page analysis
  - `preflight_validator.py`: Pre-processing validation
  - `i18n.py`: Internationalization (en/uk)

**prompts/**
- Purpose: Transcription prompt templates and legacy prompt files
- Contains: Markdown templates and project-specific prompt files
- Key files:
  - `templates/`: Template files for wizard mode (with variable substitution)
  - `*.md`: Legacy prompt files (direct content, no variables)

**tests/**
- Purpose: Test suite with unit, integration, and compatibility tests
- Contains: Pytest test modules, fixtures, conftest
- Key files:
  - `unit/`: Unit tests for individual components
  - `integration/`: Integration tests for mode flows and wizard
  - `compatibility/`: Backward compatibility tests
  - `conftest.py`: Shared test fixtures
  - `verify_tests.py`: Test verification utility

**logs/**
- Purpose: Runtime-generated log files
- Contains: Session logs, AI response logs
- Generated: Yes (per session)
- Committed: No (gitignored)

**data_samples/**
- Purpose: Sample input data for testing
- Contains: Test image directories
- Key files: `test_input_sample/`, `test_input_sample_2/`, `test_input_sample_3/`

**projects/**
- Purpose: Project-specific notes and documentation
- Contains: Project directories with planning documents
- Key files: `app-install-simplification/`, `wizard-mode/`

**docs/**
- Purpose: User documentation and guides
- Contains: Markdown documentation files

**img/**
- Purpose: Branding assets
- Contains: Logo and banner images (GeneaScript branding)

**.claude/**
- Purpose: Claude AI agent configuration
- Contains: Custom commands, workflows, agents
- Key files: `commands/gsd/`, `get-shit-done/`, `agents/`, `hooks/`

**.planning/**
- Purpose: Planning documents generated by GSD workflow
- Contains: Codebase analysis documents
- Generated: Yes (by GSD commands)
- Committed: Yes (for team reference)

## Naming Conventions

**Files:**
- Snake_case: `transcribe.py`, `recovery_script.py`, `wizard_controller.py`
- Test files: `test_*.py` prefix
- Config files: `config*.yaml` or `*.yaml` in config/
- Example files: `*.example.yaml` suffix

**Directories:**
- Lowercase: `wizard/`, `tests/`, `config/`, `prompts/`
- Subdirectories: `steps/`, `unit/`, `integration/`, `templates/`

**Classes:**
- PascalCase: `WizardController`, `ModeFactory`, `AuthenticationStrategy`
- Strategy suffix: `LocalAuthStrategy`, `GeminiDevClient`
- Output suffix: `LogFileOutput`, `GoogleDocsOutput`

**Functions:**
- Snake_case: `load_config()`, `detect_mode()`, `transcribe_image()`
- Utility functions: `list_images()`, `calculate_metrics()`, `create_overview_section()`

**Variables:**
- Snake_case: `config_path`, `image_bytes`, `ai_logger`
- Constants: UPPER_CASE (e.g., `LOGS_DIR`, `DOCX_AVAILABLE`)

- Tests: `tests/unit/test_*.py` (create new test module)

**New Wizard Step:**

**New Configuration Field:**
- Validation: Update `validate_config()` in `transcribe.py` (line 184)
- Normalization: Update `normalize_config()` if needed (line 132)

**New Utility Function:**

**New Prompt Template:**
- Template file: `prompts/templates/<template_name>.md`
- Variables: Use `{{variable_name}}` syntax for substitution
- Legacy prompts: `prompts/<prompt_name>.md` (direct content, no variables)

**New i18n String:**
- Translation: Add to `wizard/i18n.py` in `TRANSLATIONS` dict (both 'en' and 'uk')

**New Test:**
- Unit test: `tests/unit/test_<module>.py`
- Integration test: `tests/integration/test_<flow>.py`
- Fixtures: `tests/conftest.py` or `tests/fixtures/`
